# 锈潮断链 · Rusttide Cutoff

**作者：Jack** · © Jack 版权所有 · **禁止任何形式转载**

黎明、阴雨、乍浦港区。乍浦港区自动化网络被入侵，巡检机械全部转为攻击模式。你是「潮汐七号」，单兵渗透：依次切断三处上行中继，杀出堆场，登上码头撤离艇。

试玩：<https://13185.github.io/rusttide-cutoff/>（电脑浏览器，需鼠标键盘）

> 玩法结构受 Felix Rieseberg 的浏览器 FPS《Saltline》启发（切断中继 → 敌人升级 → 登船撤离）。
> 除署名的第三方枪械模型外，本作**代码、场景模型、贴图、着色器、音效与文字均为独立原创实现**，没有复制《Saltline》或其任何改名副本的源码、着色器、内嵌资源、文案或标记。两款枪模来自 Gintoki1234，许可为 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，不受「禁止转载」约束，详见 NOTICE。

## 操作（电脑端）

| 按键 | 作用 |
| --- | --- |

| 左键 | 开火 |
| 右键（按住） | 瞄准（步枪全息瞄具：窗内约 1.4× 放大，红色环+中心点；霰弹枪准星珠。镜外不做全黑遮幅） |
| W A S D | 移动 |
| Shift | 冲刺（向前时） |
| 空格 | 跳跃 |
| C / Ctrl | 蹲伏 |
| **Q** | **切换突击步枪与霰弹枪**（收枪再出枪，非瞬切） |
| 1 / 2 / 滚轮 | 切枪备选 |
| R | 换弹（弹匣满或无备弹时不触发；打空自动换弹；霰弹枪逐发装填，可开火打断） |
| G | 投掷手雷 |
| V | 枪托近战 |
| E（按住 3.5 秒） | 切断中继，松开即中断 |
| Esc | 暂停 / 释放鼠标 |

## 任务流程

1. 罗盘上标出甲（西堆场）、乙（东仓库）、丙（一号岸桥下）三处中继及距离，顺序自由。
2. 每切断一处：乍浦港区升级增援（第一处后出现机械守卫，第二处后出现机械飞鸥，第三处后全面压上），并补给 60 发备弹。
3. 三处全部切断后，前往码头东侧撤离艇登船通关。
4. 结算：用时、命中率、弱点命中、击毁数 → S / A / B / C 评级。倒下后可「再次出击」。

## 敌人

| 名称 | 行为 | 弱点（伤害倍率） |
| --- | --- | --- |
| 机械猎犬 | 地面高速追击，近距离扑咬冲刺 | 头部红色传感器 ×2.5 |
| 机械飞鸥 | 空中盘旋，俯冲射出光弹 | 腹部琥珀光核 ×2.5 |
| 机械守卫 | 重型双足，臂炮三连发，持盾 | 背部散热核心 / 面罩 ×3 |

命中弱点时准星标记变为琥珀色。击毁的机械可能掉落弹药箱（守卫必掉）。

## 生命与弹药

- 生命 100，受伤 4 秒后开始恢复；躲在掩体后（附近敌人都没有视线）恢复更快。
- 「潮汐-7」突击步枪：弹匣 30，初始备弹 150（上限 240），换弹 2.15 秒。
- 「港务-12」泵动霰弹枪：弹匣 6，备弹 30（上限 48），逐发装填。
- 破片手雷最多 3 枚（开局 2 枚），近战随时可用。弹药箱同时补给步枪、霰弹与手雷。
- HUD 显示「换弹中」进度与「按 R 换弹」提示。

## 画面与音频

- Three.js r170（MIT）。主要模型和第一人称手部用 Blender 4.2 脚本（`art/build_assets.py`）建出并导出 glb；PBR 贴图由 `art/bake_textures.py` 烘焙（反照率 / 法线 / ORM，含锈痕、雨痕与积水）。
- 集装箱实例化 + 远近 LOD，岸桥 / 轮胎吊 / 撤离艇 / 中继柜 / 三种敌人均为 glb。第一人称双手有肌腱与指节，开枪时有握紧与前臂胀起后回弹。
- 步枪为原创全息瞄具：按住右键开镜时视野略收，窗框与遮罩可见，窗内二次渲染约 1.4× 放大，红色环+中心点分划，镜外不做全黑遮幅。霰弹枪使用机匣顶与准星珠瞄准。
- 自写黎明阴雨天空着色器、天空 PMREM 环境光、软阴影、SSAO、平面反射湿地（含积水）、雨丝、雾。中继柜不再靠自发光凑合，改用面板与补光。
- 敌人使用 1 米格网 A* 寻路、侧翼迂回、守卫找掩体、飞鸥贝塞尔俯冲，并做粘墙检测。
- 后期：轻度 SSAO、柔和泛光、低角度体积光、ACES 色调映射、胶片微颗粒、轻度 FXAA（默认偏低锐度，不做锐化拉边）。
- 画质：低 / 中 / 高 / 极高（低画质关闭反射、阴影与后期；各级有不同 LOD 距离）。
- 音频：Web Audio 实时合成——雨声、风、海浪、远处汽笛、张力低音垫与心跳、分层枪声与卷积混响、换弹序列、机械敌人的伺服/液压/尖鸣声（HRTF 3D 定位）、中继切断电弧声。主压缩+限幅，设置里可调总音量 / 环境 / 音效与静音。
