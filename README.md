# 锈潮断链：午夜禁区 · Rusttide Cutoff

**作者：Jack** · © Jack 版权所有 · **禁止任何形式转载**

凌晨 5:18，乍浦港区突然失去联系。你是最后一名调查人员「潮汐七号」，进入浓雾中的集装箱港区，关闭三座异常中继，查明人员失踪的原因，再登上码头撤离艇。

当前版本是可战斗的午夜禁区：冷青夜色、手电筒、闪电，以及源源不断的发光巡夜者。三座中继各有一只看守，打死并捡起钥匙卡才能切断。

试玩：<https://13185.github.io/rusttide-cutoff/>（电脑浏览器用鼠标键盘；手机 / 平板横屏可用触屏操作）

## 操作（电脑端）

| 按键 | 作用 |
| --- | --- |
| 鼠标 | 视角（点击画面进入指针锁定） |
| 左键 | 开火 |
| 右键（按住） | 瞄准（步枪全息瞄具：主视野略收，窗内约 1.55× 放大，红色环+中心点；霰弹枪准星珠。镜外不做全黑遮幅） |
| W A S D | 移动 |
| Shift | 冲刺（向前时） |
| 空格 | 跳跃 |
| C / Ctrl | 蹲伏 |
| **Q** | **切换突击步枪与霰弹枪**（收枪再出枪，非瞬切） |
| 1 / 2 / 滚轮 | 切枪备选 |
| **F** | **手电筒开关**（窄锥绑在视角上，再按关闭；关闭后仍有极弱环境光可慢走认路） |
| R | 换弹（弹匣满或无备弹时不触发；打空自动换弹；霰弹枪逐发装填，可开火打断） |
| G | 投掷手雷 |
| V | 枪托近战 |
| E（按住 3.5 秒） | 持有对应中继钥匙卡时切断中继，松开即中断 |
| Esc | 暂停 / 释放鼠标 |

## 操作（手机 / 平板触屏）

只有真正用手指点过屏幕才会切到触屏模式（也可加 `?touch=1` 测试）。电脑端不受影响：鼠标点击照常进入指针锁定，右键照常开镜；带触屏的笔记本先用手指、后用鼠标点击，也会照常锁定鼠标。

默认「二指」布局：

| 位置 | 作用 |
| --- | --- |
| 左下按住拖动 | 浮动摇杆走路，推得越远走得越快；推过外圈约八成并朝前才冲刺（摇杆圈变琥珀色并显示「冲刺」，脚步更响，不会自动冲刺） |
| 右半屏空白处划动 | 转视角（固定速度、不加速；腰射与开镜分开灵敏度） |
| 右下「开火」 | 按住射击（步枪全自动，霰弹枪每按一次一发）；按着可直接拖动瞄准 |
| 「瞄准」 | 点按开镜 / 退出（设置可改成长按） |
| 「换弹」「换枪」「跳」「雷」 | 同 R / Q / 空格 / G |
| 左侧「蹲」 | 点按切换蹲伏 |
| 左侧「手电」 | 干净点按才开关（滑过或按下拖走都不触发） |
| 屏幕下方情境按钮 | 靠近中继时出现。没有钥匙卡时提示去打看守；拿到钥匙后按住 3.5 秒切断，带进度圈 |
| 左上 ❚❚ | 暂停（暂停菜单里有设置与全屏） |

「三指」布局：左上加大「开火」给左手食指，右侧开火缩小，「瞄准」移到右上。

暂停 → 设置 → 触屏操作：布局（二指 / 三指）、按钮大小、透明度、瞄准点按或长按、摇杆浮动或固定、视角灵敏度、开镜灵敏度、陀螺仪（关闭 / 仅开镜 / 始终，iOS 会先弹授权）、轻度辅助瞄准（准星贴近敌人时略减速、划动时轻微吸附；没有敌人时不起作用）。设置保存在本机浏览器。

手机适配：

- 横屏游玩；竖屏时显示「请横屏游玩」并自动暂停。点开始时尝试全屏并锁定横屏（安卓 Chrome 支持；iOS Safari 与微信内置浏览器没有全屏接口，会自动忽略）。
- 禁止双指缩放、双击放大、页面滚动、长按菜单与选中文字；按钮避开刘海与底部手势区（safe-area）。
- 第一次触摸时解锁声音，首次开局提示「建议戴耳机」。
- 「手机」画质档（触屏模式自动选用，可在设置里改，手动选过就不再自动改）：分辨率上限 1.25 并按帧率在 0.8–1.25 之间自适应；关阴影、关平面反射；后期只留色调映射、雾和锐化（去掉 SSAO、泛光与光柱）；雨丝减到约 900 条；动态路灯减为 2 盏（手电与中继灯保留）；LOD 与远裁剪收近（夜雾 150 米外本来就看不见）；瞄准镜画中画降到 320；用低贴图枪模；曝光与环境光略提亮，小屏夜里也看得清路。
- 手机图形资源被系统回收时显示「画面中断」，点一下重新载入。

## 任务流程

1. 罗盘标出甲（西堆场）、乙（东仓库）、丙（一号岸桥下）三座异常中继。每座旁边站着一只更大的巡夜者。
2. 打死看守，捡起掉落的中继钥匙卡（A / B / C）。没有对应钥匙卡时，按住 E 不会切断，界面会写明还缺哪一张。
3. 持卡按住 E 3.5 秒切断。切断乙之后，对讲里有残缺录音：「别关最后一个……」。切断丙之后，电台说「你把它放出来了。」
4. 三座都切断后，撤离艇才亮灯。登上码头东侧的艇。离岸后船舱后方敲三下。
5. 巡夜者从视野外持续刷新，切断中继后更密。结算仍是用时、命中率、弱点、击毁数。第一次打完大约要八到十二分钟，不是几十秒。

## 敌人

巡夜者是残破工业机械，夜里靠发光缝、眼和一圈轮廓认出来：猎犬与守卫是红橙色，飞鸥是病态青。它们会追、会咬、会射击。

第一关有三只看守（巡夜者·A / B / C），各守一座中继。体型更大，血量约 1680，HUD 上有血条。它们会点射一串炽热弹，也会短冲再砸一圈冲击。打死才掉钥匙卡。

同时存在的普通巡夜者有上限（电脑约 8，手机画质约 4），点光源只开在最近的几只身上，避免把夜里的灯数打爆。

## 生命与弹药

- 生命 100，受伤 4 秒后开始恢复；躲在掩体后（附近敌人都没有视线）恢复更快。
- 「潮汐-7」突击步枪：弹匣 30，初始备弹 150（上限 240），换弹 2.15 秒。
- 「港务-12」泵动霰弹枪：弹匣 6，备弹 30（上限 48），逐发装填。
- 击毁巡夜者经常掉弹药箱；看守必掉钥匙卡和一箱弹药。切断中继也会补弹。弹药够打完三只看守，但打不中就会紧。
- 破片手雷最多 3 枚（开局 2 枚），近战随时可用。弹药箱同时补给步枪、霰弹与手雷。
- HUD 显示「换弹中」进度与「按 R 换弹」提示。

## 画面与音频

- Three.js r170（MIT）。主要模型和第一人称手部用 Blender 4.2 脚本（`art/build_assets.py`）建出并导出 glb；PBR 贴图由 `art/bake_textures.py` 烘焙（反照率 / 法线 / ORM，含锈痕、雨痕与积水）。
- 集装箱实例化 + 远近 LOD，岸桥 / 轮胎吊 / 撤离艇 / 中继柜 / 三种敌人均为 glb。第一人称双手有肌腱与指节，开枪时有握紧与前臂胀起后回弹。
- 步枪为原创全息瞄具：按住右键开镜时主视野略收，窗框可见，窗内按窗口张角二次渲染约 1.55× 放大（相对窗外，不是把宽视野塞进小窗），红色环+中心点分划，镜外不做全黑遮幅。霰弹枪使用机匣顶与准星珠瞄准。
- 自写破晓前冷青夜空、极弱月光轮廓、天空 PMREM 环境光、软阴影、SSAO、平面反射湿地（含积水）、雨丝、更浓但仍可读的雾。主通道有稀疏高压钠灯与少量冷白探照，动态灯数量受控。按 F 打开手电筒。
- 集装箱使用更干净的工业漆（蓝、红、橙、绿、白为主），锈和剥漆集中在边角；锁杆为较亮的冷金属。
- 后期：SSAO、克制泛光、ACES 色调映射、胶片微颗粒、轻度反锐化（保持偏清晰，不做柔焦）。
- 画质：低 / 中 / 高 / 极高 / 手机（低画质关闭反射、阴影与后期，并减少动态灯；各级有不同 LOD 距离；手机档见上文）。
- 音频：Web Audio 实时合成，不引入外部音乐文件。平静层为雨、风、海浪、远处汽笛与极低频嗡声；远处有金属碰撞、对讲杂音和立体声定位的远脚步。切断第一座中继后有断电声和一次更近的远脚步。大约每 15–40 秒一道闪电：画面在约 0.4 秒内闪两三次（天空、曝光和天光一起抬亮），雷声按距离晚到。主压缩+限幅，设置里可调总音量 / 环境 / 音效与静音。
