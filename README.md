# 锈潮断链：午夜禁区 · Rusttide Cutoff

**作者：Jack** · © Jack 版权所有 · **禁止任何形式转载**

凌晨 5:18，乍浦港区突然失去联系。你是最后一名调查人员「潮汐七号」，进入浓雾中的集装箱港区，关闭三座异常中继，查明人员失踪的原因，再登上码头撤离艇。

当前版本是「午夜禁区」第一步（氛围版）：冷青夜色、稀疏工业灯、手电筒、分层环境声，以及更干净的饱和工业漆集装箱。常规机械敌军波次已关闭，中继、登艇、死亡重开与暂停仍可用。

试玩：<https://13185.github.io/rusttide-cutoff/>（电脑浏览器，需鼠标键盘）

> 结构启发仍来自 Felix Rieseberg 的浏览器 FPS《Saltline》（关闭中继、登船撤离）。本版已转向工业恐怖生存氛围，不再以清怪波次为主。

## 操作（电脑端）

| 按键 | 作用 |
| --- | --- |
| 鼠标 | 视角（点击画面进入指针锁定） |
| 左键 | 开火 |
| 右键（按住） | 瞄准（步枪全息瞄具：窗内约 1.4× 放大，红色环+中心点；霰弹枪准星珠。镜外不做全黑遮幅） |
| W A S D | 移动 |
| Shift | 冲刺（向前时） |
| 空格 | 跳跃 |
| C / Ctrl | 蹲伏 |
| **Q** | **切换突击步枪与霰弹枪**（收枪再出枪，非瞬切） |
| 1 / 2 / 滚轮 | 切枪备选 |
| **F** | **手电筒开关**（窄锥绑在视角上，再按关闭；关闭后仍有极弱环境光可慢走认路） |
| R | 换弹（弹匣满或无备弹时不触发；打空自动换弹；霰弹枪逐发装填，可开火打断） |
| G | 投掷手雷 |
| V | 枪托近战 |
| E（按住 3.5 秒） | 关闭中继，松开即中断 |
| Esc | 暂停 / 释放鼠标 |

## 任务流程

1. 罗盘上标出甲（西堆场）、乙（东仓库）、丙（一号岸桥下）三座异常中继及距离，顺序自由。
2. 关闭中继后补给少量备弹。本版不会因此刷新机械敌军。切断第一座后，远处会传来更近的金属脚步（无实体）。
3. 三座全部关闭后，前往码头东侧撤离艇登船通关。
4. 结算：用时、命中率、弱点命中、击毁数 → S / A / B / C 评级。倒下后可再次调查。

## 敌人

本步关闭常规波次刷新，港区开局没有猎犬、守卫或飞鸥。相关代码仍保留，供下一步改造成主怪物「巡夜者」。

## 生命与弹药

- 生命 100，受伤 4 秒后开始恢复；躲在掩体后（附近敌人都没有视线）恢复更快。
- 「潮汐-7」突击步枪：弹匣 30，初始备弹 150（上限 240），换弹 2.15 秒。
- 「港务-12」泵动霰弹枪：弹匣 6，备弹 30（上限 48），逐发装填。
- 破片手雷最多 3 枚（开局 2 枚），近战随时可用。弹药箱同时补给步枪、霰弹与手雷。
- HUD 显示「换弹中」进度与「按 R 换弹」提示。

## 画面与音频

- Three.js r170（MIT）。主要模型和第一人称手部用 Blender 4.2 脚本（`art/build_assets.py`）建出并导出 glb；PBR 贴图由 `art/bake_textures.py` 烘焙（反照率 / 法线 / ORM，含锈痕、雨痕与积水）。
- 集装箱实例化 + 远近 LOD，岸桥 / 轮胎吊 / 撤离艇 / 中继柜 / 三种敌人均为 glb。第一人称双手有肌腱与指节，开枪时有握紧与前臂胀起后回弹。
- 步枪为原创全息瞄具：按住右键开镜时视野略收，窗框与遮罩可见，窗内二次渲染约 1.4× 放大，红色环+中心点分划，镜外不做全黑遮幅。霰弹枪使用机匣顶与准星珠瞄准。
- 自写破晓前冷青夜空、极弱月光轮廓、天空 PMREM 环境光、软阴影、SSAO、平面反射湿地（含积水）、雨丝、更浓但仍可读的雾。主通道有稀疏高压钠灯与少量冷白探照，动态灯数量受控。按 F 打开手电筒。
- 集装箱使用更干净的工业漆（蓝、红、橙、绿、白为主），锈和剥漆集中在边角；锁杆为较亮的冷金属。
- 后期：SSAO、克制泛光、ACES 色调映射、胶片微颗粒、轻度反锐化（保持偏清晰，不做柔焦）。
- 画质：低 / 中 / 高 / 极高（低画质关闭反射、阴影与后期，并减少动态灯；各级有不同 LOD 距离）。
- 音频：Web Audio 实时合成，不引入外部音乐文件。平静层为雨、风、海浪、远处汽笛与极低频嗡声；远处有金属碰撞、对讲杂音和立体声定位的远脚步。切断第一座中继后有断电声和一次更近的远脚步。主压缩+限幅，设置里可调总音量 / 环境 / 音效与静音。
