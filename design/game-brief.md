## 故事（不要写在标题屏上剧透）

凌晨 5:18，乍浦港区突然失去联系。自动化码头停运，工作人员失踪，监控里出现无法解释的黑影。玩家是最后一名调查人员「潮汐七号」，被派去关闭三座异常中继站。

进入港区后：机器明明已经断电却还在自行移动；集装箱后传来金属敲击；对讲机里有人呼叫，声音却来自已经失踪的队员。每关闭一座中继，港口更暗一分。

**反转（第三步才完全揭开）**：三座中继不是控制怪物的装置，而是困住它的装置。玩家以为自己在排除故障，实际上一步步把它放出来。切断最后一座后，对讲机说「你把它放出来了。」撤离艇离开码头时，船舱后方敲三下，切黑结束。

吉利达招工横幅与华晨达货柜仍是港区真实氛围，不当反派。

## 核心玩法

- 有枪，但弹药很少；枪声和奔跑会吸引正在巡游的东西。
- 手电筒（F 开关）能照亮集装箱巷道，也会暴露位置（第二步才让怪物真正响应）。
- 第一版只做一个主怪物「巡夜者」：残破工业机械、异常肢体、单点红光。行为：游荡 / 调查声源 / 追击 / 失去目标后搜索再离开。子弹只能暂时击退，不能轻易杀死。
- 不做技能树、升级、复杂装备。
- 电脑操作不变：指针锁定、左键开火、按住右键开镜、WASD、Q 换枪、R 换弹、E 按住关闭中继、Esc 暂停。Shift 仍为冲刺（第二步起算噪音）。

## 十二分钟节奏

| 时间 | 节拍 |
|------|------|
| 0–2 分 | 港区异常。无可见敌人。雨、风、海浪、远处箱体碰撞。一盏路灯熄灭。对讲：「不要往后看。」回头什么也没有。 |
| 2–4 分 | 切断 A。区域停电，远处高大人影一闪即逝，第一次沉重金属脚步。 |
| 4–7 分 | 去 B 的路上第一次被追。有限子弹只能击退，或绕箱躲开。玩家明白自己是猎物。 |
| 7–10 分 | 切断 B 后残缺录音：「别关最后一个……那些东西不是靠中继控……」系统仍要求切断 C 才能启动撤离艇。 |
| 10–12 分 | 切断 C，全港停电。「你把它放出来了。」巨大黑影出现，限时冲向撤离艇。离岸后三下敲击，切黑。 |

## 三步开发

1. **氛围（本轮执行）**：低照度、浓雾、少量工业灯、手电筒、环境声与远处异常脚步。暂不放真怪物。集装箱改为真实饱和工业漆（蓝、红、橙、绿、白为主）。暗，但必须看得清路。控制浏览器性能。
2. **威胁**：复用并改造现有敌人系统，做成一名巡夜者（游荡、听声、追击、失去目标）。少量反击机会。可先只开 A、B 验证躲避是否有趣。
3. **完整体验**：三座中继的剧情事件、最终追逐与撤离结局。
