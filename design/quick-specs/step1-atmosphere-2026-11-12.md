# Quick Design Spec: 午夜禁区第一步 · 氛围

**Type**: New Small System  
**Scope**: 把现有黎明突击港区改成可走、可关中继、可登艇的午夜禁区氛围版。含光照、雾、手电筒、分层环境声、集装箱工业漆与故事文案转向。本步不实现巡夜者实体，不改枪械手感与开镜逻辑。  
**Date**: 2026-11-12  
**Estimated Implementation**: 数小时（本机现有工程上改）

## Overview

玩家进入乍浦港区时已是凌晨、低能见度。工业探照灯和手电是主要光源，集装箱是可辨认的蓝红橙绿白货柜，而不是灰石头。声音以雨、风、海、远处金属和极低频嗡声为主，偶尔传来远脚步。三处中继与撤离艇仍可完成，但普通机械敌军波次关闭，让氛围能被听见、被看见。

## Core Rules

1. **时段与光**：故事时间仍为凌晨 5:18（标题/字幕），视觉改为深夜/破晓前：去掉暖色黎明主光，改用冷青雾与稀疏高压钠灯/冷白探照灯。主方向光极弱，只用于轮廓，不把场景晒亮。
2. **能见度**：雾比现在浓，但巷道 15–25 米内仍能看清箱体颜色、路标和中继。禁止纯黑填满画面。地面潮湿反光保留，作为认路线索。
3. **工业灯**：复用现有灯杆与仓库门口灯，改为少量点/聚光（总数严格控制，建议场景有效动态灯 ≤ 8，加 1 只手电）。部分灯可轻微闪烁。开局 0–2 分钟内，主通道前方一盏路灯熄灭一次（固定事件，可重复游玩时仍触发一次）。
4. **手电筒**：按 F 开关（再按关闭）。灯绑在相机上，窄锥、近亮远衰，轻微随走步晃动。关闭时仍有极弱环境光，可慢走认路，但巷道深处偏暗。设置/操作说明写上 F。不要占用右键（开镜）或 Q（换枪）。
5. **集装箱漆面**：板面不用满墙耐候钢锈斑做主纹理。改用更干净的工业漆（法线减弱，避免和几何波纹叠出石墙感）。锈、剥漆、流痕集中在边角、底部和接缝。实例颜色以饱和箱蓝、信号红、橙、绿、白为主，海军蓝与旧灰为少数。锁杆/铰链用较亮的冷金属，和门板拉开对比。箱号与船司标志（已有原创图集）提高可见度。华晨达两只海军箱保持可识别。
6. **敌人**：本步关闭常规波次刷新（猎犬/守卫/飞鸥不在场）。保留敌人代码，用开关关掉即可，供第二步改造为巡夜者。中继、登艇、死亡/重开、暂停仍可用。
7. **声音（本步实现「平静 + 远处不对劲」，不做追逐层）**：
   - 底层：雨、风、海浪、远处汽笛（可沿用并压低、更空）。
   - 不安层：极低频、几乎听不出的持续嗡声。
   - 环境异常：间隔出现的集装箱金属咯吱、远处碰撞、偶发对讲杂音（无语义或极短气声）。
   - 远脚步：立体声定位的沉重金属脚步，始终较远，从箱巷一侧绕过，不对应实体。
   - 切断第一座中继：电流切断声，随后一次更近的远脚步（仍无实体）。
   - 全部 Web Audio 合成，不引入外部音乐文件。
8. **文案**：标题可作「锈潮断链」主标题 + 「午夜禁区」副标题。开始简报与电台开场改为：失联、调查、关闭三座异常中继、失踪人员。禁止在标题屏或开场剧透「中继是囚笼」。关于页注明玩法转向工业恐怖生存，Saltline 启发仍可保留为结构启发。
9. **操作与发布**：指针锁定、右键开镜、Q 换枪、桌面 FPS 判定一律保持。画质档位保留。发布到原 Pages，不 force-push，不动 paladin-isekai 与 dustline-raid。

## Tuning Knobs

| Knob | Default | Range | Rationale |
|------|---------|-------|-----------|
| 雾密度 | 现有约 0.008 提到约 0.014–0.018 | 以 20m 可读、40m 溶入雾为准 | 恐怖靠能见度边缘，不是靠瞎 |
| 环境光强度 | 约为现有黎明的 25–35% | 手电关闭时仍能辨认近处箱色 | 可读性 |
| 手电锥角 | 约 25–35° | 太宽不像手电，太窄没法走路 | |
| 手电距离 | 约 22–28 m | 刚好照到下一弯巷道 | |
| 远脚步最近距离 | ≥ 28 m | 本步绝不走到身边 | 保留未知 |
| 饱和箱色占比 | ≥ 70% 实例为蓝/红/橙/绿/白 | 灰与脏棕 ≤ 20% | 像真港口，不像石头 |

数值可写在 `js/` 里的清晰常量或集中配置对象，不必为了形式新建 JSON 管线。

## Acceptance Criteria

- [ ] 同机位截图：港区从暖黎明变为冷、暗、有工业灯的午夜，但箱体颜色和路仍可读。
- [ ] 手电 F 可开关，锥光可见，不影响开镜与换枪。
- [ ] 集装箱近看是喷漆钢板（蓝/红等），不再像湿石墙；锁杆或箱号至少有一项在近景可读。
- [ ] 开局无敌军刷新；可走到并关闭中继、可登艇（若三座都关）。
- [ ] 能听到低频嗡、远处金属和至少一次空间化远脚步；切断第一座中继后有断电声和一次脚步。
- [ ] 标题/简报/电台开场已转向调查异常，未剧透反转。
- [ ] Playwright 冒烟通过（按新逻辑调整：无清怪要求；仍要指针锁定路径、Q 换枪、右键 ADS、无页面报错）。
- [ ] 软件渲染截图会偏暗，交付时说明；真机不应黑到迷路。画质档在中/高下动态灯数量受控。
- [ ] paladin-isekai Last-Modified 不变；dustline-raid 提交不变。
