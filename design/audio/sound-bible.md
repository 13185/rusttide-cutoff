# 声音设计：午夜禁区

全部用 Web Audio 实时合成，不引入外部音乐或采样版权文件。声音要帮玩家判断方位，不靠无来源的突然巨响吓人。

## 四层（随危险程度叠加）

1. **平静（第一步就要有）**  
   几乎没有「曲子」。雨、风、海浪、远处汽笛、箱体被风吹的咯吱。一层很低、几乎听不出的嗡声，让人一直不安。

2. **它在附近但没发现你（第一步用「远脚步 / 远金属」代替实体）**  
   低音慢慢升起一点。金属拖拽、远处重脚步、对讲杂音、一下听不清来源的呼吸或气声。立体声定位，能感觉方向，看不见来源。

3. **被追（第二步）**  
   心跳加快，低音变满，刺耳金属摩擦加急促脉冲。巡夜者脚步变快变重，越近越响，方位必须准。

4. **甩掉之后（第二步）**  
   不立刻恢复平静。先空白几秒，只剩喘气和雨，然后远处再一下金属敲击。

## 关键剧情声（第一步先做切断 A；其余第二、三步）

- 切断 A：全场电流「啪」地断掉，随后第一次较近的沉重脚步。
- 切断 B：残缺录音 + 电流干扰，声音像失踪队员（第三步写词，第二步可先留接口）。
- 切断 C / 结局：音乐与垫音全部抽空，金属摩擦逼近；离岸后完全安静，船舱后敲三下，切黑。

## 技术

- 远脚步与金属用 HRTF 或至少 stereo panner + 距离衰减，给世界坐标。
- 主压缩与限幅保留，避免层叠时削波。
- 设置里已有总音量 / 环境 / 音效 / 静音，新层走环境或单独「氛围」增益，不要绕过静音。
